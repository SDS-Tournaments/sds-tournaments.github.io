# SDS — инструкции для Claude

Сайт онлайн-чемпионата Sad Drift Series (CarX Drift Racing Online 2). Angular 22 + Supabase + GitHub Pages.

## База знаний
**Вики проекта — `docs/wiki/` (начать с `docs/wiki/README.md`).** Там всё: устройство, база, страницы, админка, плашки, подсчёт,
дизайн и вкусы владельца, грабли, бэклог, журнал заливов. Пользоваться ею вместо повторного изучения кода.

**Перед каждым заливом в прод (`git push`) обязательно обновить вики:** затронутые страницы + запись в `docs/wiki/changelog.md`
(+ `backlog.md`, если что-то закрыто/появилось). Вики коммитится до пуша. Если вики расходится с кодом — исправить вики.

## Правила работы (кратко, подробно — docs/wiki/workflow.md)
- Общаться только по-русски, просто: владелец — не разработчик.
- Изменения: сборка + тесты + локальный коммит → владелец проверяет на http://127.0.0.1:4200 → **push только по команде «заливай»**.
- Миграции: давать текст SQL в сообщении (не путь к файлу), выполнять на тестовой и боевой базе. Edge-функции деплоит владелец — давать команды.
- Никогда не хранить в коде/вики секретные ключи (`sb_secret_…`, service_role), не просить пароль БД и Steam API key, не входить под владельцем.
- Не ослаблять `staffGuard` и RLS.
- Проверять визуал внимательно (ширины, наложения, обрезки), в ответе честно писать, что проверено, а что нет.
