# Sad Drift Series — сайт чемпионата

Подтверждённое описание задумки (2026-10-11).

- **Что:** сайт онлайн-чемпионата по дрифту в CarX Drift Racing Online 2 — витрина лиги + пульт судейства + источник плашек для стрима (OBS).
- **Для кого:** пилоты, команды, зрители, организатор и судьи, управляющий трансляцией.
- **Этап:** регистрация → группы и очередь квалификации → 3 заезда (1 прогрев + 2 в зачёт, лучший) → 3 судьи, у каждого свой критерий (угол / стиль / траектория), веса на этап, вносит один человек → сетка строится автоматически (Top 32/16/8, лидеры квалификации проходят по баям при нехватке пилотов) → дуэли: лидер по квалификации, 2 заезда, 3 голоса судей (лидер / чейзер / OMT), максимум 2 OMT, затем побеждает лучший по квалификации; дуэль за 3-е место; кнопки дисконнект / техпоражение / спин.
- **Зачёт:** очки RDS GP 2024 (квалификация + дуэли), личный и командный (до 8 пилотов, в зачёт 3 лучших). Сезоны с настраиваемым числом этапов, новый сезон обнуляет очки, архив с чемпионами. Тай-брейки по RDS. Таблицы очков настраиваются.
- **Стиль:** DESIGN.md «Tiffany Noir» — ночной тоге (главная) + телеметрия (таблицы, пульт).
- **Технологии:** Angular + Supabase + Netlify, свой домен, вход только через Steam (ник + аватар).
- **Языки:** RU (основной, по умолчанию) + EN переключателем. Админка/пульты — только RU. Плашки стрима — язык выбирается в пульте.
- **v1:** главная с этапом и Twitch; рейтинги, сетка, архив, регламент; профили пилотов и страницы команд; личный кабинет и регистрация на этап; пульт судьи и управляющего; плашки OBS; спонсоры (настраиваемые, в т.ч. на стриме); роли доступа; FIFA-карточка пилота; «паутинка» навыков; Discord-оповещения; достижения.
- **v2:** прогнозы зрителей, head-to-head и соперничества, «Итоги сезона», пилот этапа, клипы, календарь.
- **Не делаем:** выгрузку из игры, приём денег, мобильное приложение, вход без Steam, другие языки кроме RU/EN.
- **Бюджет:** бесплатные тарифы; платим только за домен.
