# Публичные страницы и личный кабинет

Все публичные страницы — RU/EN, лоадер до готовности данных, `reveal`-появление, темы сайта.

## Оболочка (app.html)
- **Шапка-«острова»:** отдельные плавающие плашки — лого SDS, меню (Зачёт, Этапы, Пилоты, Команды, Регламент), справа:
  выбор темы (NOIR/…/LEGEND), RU/EN, вход Steam / ник + выход, колокольчик протестов (штаб), «Админка» (штаб). При прокрутке — плотнее + мягкое затемнение.
  Во время этапа — LIVE-плашка.
- **Подвал:** слева SDS, © 2026, **Discord** (ссылка из `app_settings.discord_invite`, нет ссылки — нет пункта), Архив;
  справа «Генеральный спонсор: CarX Technologies» (из `sponsors`, tier general). На `/attack-shark` — ещё «Партнёр сезона: Attack Shark».
- **Плашка-напоминание Discord** внизу экрана: пилот вошёл, а ник Discord не указан. Не показывается в `/me`, `/admin`, `/judge`, `/broadcast`.
- **Загрузочный экран «SAD»** (index.html + boot.ts): контурные буквы заливаются по мере ответов базы.
- Своя полоса прокрутки (`scroll-rail`) на компьютере: шкала с делениями и светящаяся точка цвета темы.
- Фон: свечения, сетка, зерно; в режиме `html.live` — LIVE-эффекты.

## `/` Главная (`pages/home.ts`)
- Герой: чип, «Sad Drift Series», лид, кнопки «Этапы сезона» / «Зачёт», генеральный спонсор. Фоновая надпись **ドリフト** —
  только контур 2.5px (без заливки); во время этапа светится и пульсирует.
- **Карточка ближайшего этапа** (`next-stage`): два дня (День 1 · Квала / День 2 · Top 32) плитками, таймер (до квалы; при `qual_done` — до парных),
  «N пилотов уже записались», кнопка регистрации, **хайп этапа** (10 уровней, см. [design.md](design.md)).
- LIVE-блок (этап в qualifying/battles): Twitch + `live-stage`. Высота панели справа = высоте видео 16:9 (`.side { height: 0; min-height: 100% }`), сама панель не прокручивается: в квале прокручивается только таблица (все пилоты, своя бирюзовая полоса на пунктире, края тают), в парных при нехватке места сжимается «Далее».
  Кнопка **«⤢ Широкий экран»** в углу видео: блок на всё окно поверх сайта (fixed, z-index 200), видео максимально, панель с голосованием справа на всю высоту; Esc/«✕ Свернуть» — назад (html.live-wide гасит transform у .page-in/[reveal] и прокрутку).
  Блок: (топ квалификации или текущая дуэль «Сейчас на трассе»)
  + **прогноз зрителей** (`prediction-poll`, логика — `predict.ts`): в квале «Попытка N: сколько наберёт ник?» — <80 / 80+ / 85+ / 90+ / 95+ / 100
  (во время прогрева — уже за 1-ю попытку), в парных «Кто победит в дуэли?». Без входа, один голос с браузера (localStorage `sds-voter`),
  после голоса — распределение %, свой вариант подсвечен. Закрывается само, когда судьи сохранили оценку / решили дуэль. Тот же блок — на странице этапа.
- **Дорога сезона** (`season-road`): этапы на линии, огонёк едет по времени к следующему этапу, победители пройденных.
- Лидеры сезона: топ-5 пилотов, топ-3 команды → «Полный зачёт». «Как проходит этап» — 3 шага (день 1 / день 2). Спонсоры.

## `/standings` Зачёт
Личный (очки по каждому этапу) и командный, вкладки, выбор сезона (`?season=ID`). Кэш зачёта на минуту (`data/standings.ts`).

## `/stages` Этапы — **билеты**
Каждый этап — вертикальный билет: сверху статус, название, трасса, «Квала»/«Top 32» с датами, победитель 🏆;
линия отрыва с полукруглыми вырезами; корешок «Этап 01» + штрихкод или «Регистрация открыта →» / «Смотреть →».
- Статусы: регистрация — бирюзовая рамка и свечение по форме билета; идёт — красная рамка с пульсацией; завершён — приглушён.
- **Наведение:** корешок скручивается в рулон справа на 15% (`--cut: 85%`), рулон — объёмный цилиндр с бликом и витками на торцах,
  перед ним тень сгиба. **Клик:** рулон за 0.18 с докатывается до левого края и улетает влево, переход через ~0.36 с.
  Ctrl/Shift/средняя кнопка — обычная ссылка; reduced motion — переход сразу. Реализация: `@property --cut`, `.stub` с `clip-path`, `.roll`, `.lip`.

## `/stages/:id` Этап
Блок **«Трасса»** (если задан): карта от дизайнера (клик — открыть целиком) и таблица баллов по зонам в духе макета: строки — траектория/угол/стиль,
колонки — зоны по порядку, «Итого» подсвечено; на телефоне листается вбок, названия критериев закреплены.
Вкладки (квалификация, сетка, итоги), живые через Realtime; дерево сетки (`bracket-tree`) с подсветкой пути победителя, дуэль за 3-е отдельно.

## `/pilots` Пилоты, `/pilots/:steamId` Профиль
- Список по уровню FIFA-карточки (Legend → Bronze, затем без рейтинга), поиск по нику и номеру.
- Профиль: обложка-ливрея, машина, команда, статистика, «паутинка» навыков (`radar`), **FIFA-карточка** (`pilot-card`, скачать PNG),
  полка ачивок (все 24, полученные горят со счётчиком), история этапов.
- **FIFA-карточка:** OVR (рейтинг; «100» уменьшен, чтобы не касаться короны), OVR-подпись, аватар, ник, команда, LIN/ANG/STY/WIN, уровень · машина.
  Стартовый номер на карточке **не показывается** (решение владельца). Чемпион (wins > 0): фольга, корона со звёздами побед + «CHAMPION»,
  лавровый венок вокруг аватара (листья могут выходить за рамку svg — `overflow: visible`).

## `/teams`, `/teams/:id`
Команды сезона с местом в зачёте; страница команды — состав, место, очки по этапам (сумма лучших `team_counted`).

## `/archive`, `/rules`
Архив завершённых сезонов с чемпионами. Регламент — Markdown из `app_settings` (RU/EN), оглавление по `##`.

## `/me` Личный кабинет
- Шапка: аватар, номер, ник, Steam ID, машина; выход. «Мои протесты» (подача 5 мин после проигранной дуэли, статусы).
- **Карточка и навыки** (паутинка + FIFA-карточка), полка ачивок.
- **Сезон:** карточка **Discord** (ник, своя кнопка «Сохранить»; пока пусто — жёлтая подсветка) → **билет записи на этап** (`stage-signup`)
  и «Моя команда» (`my-team`: создать, заявка, приглашения, состав, логотип).
  - Билет записи: «SDS · Билет пилота», этап, трасса, два дня, «записалось: N»; корешок: «Пилот #27», штрихкод,
    кнопка «Записаться» или ссылка «Отменить участие»; записан — штамп «✓ ДОПУЩЕН» поверх штрихкода (с ударом).
    Без ника Discord или номера кнопка неактивна, подсказки под билетом. Первая запись закрепляет номер (confirm).
- **Профиль пилота:** стартовый номер (`number-picker`: наклейка, сетка свободных/занятых, случайный), машина (каталог), «о себе» RU/EN (500),
  ливрея (сжатие WebP). Сохранение — плавающая капсула «Есть несохранённые изменения».

## `/attack-shark` (коллаборация, не в меню)
Наследует `Home` (те же данные), свой вид: океан с каустикой и пузырями, волны, 3D-акулы (`shark-scene`, Three.js, модель
`public/models/shark.glb` 911 КБ, CC BY 4.0 «Animated Swimming Great White Shark Loop» — LasquetiSpice, подпись внизу страницы),
заголовок «Sad Drift Series × Attack Shark», бегущая строка, «Маршрут хищника», блок партнёра (заглушки преимуществ — согласовать с Attack Shark),
«Арсенал хищника» — девайсы со ссылками на attackshark.com. Переведена на EN (`shark.*`). Отдаётся через 404.html — поисковики не индексируют.
Акулы: проход раз в 6–14 с, неровный темп (подкрадывается → рывок → скольжение), хвост бьёт по скорости; пауза вне экрана; без reduced motion/saveData.
