# Админка и пульты (только RU)

Доступ: `staffGuard` (admin и staff); реальные права — RLS. После выхода из админки чистится кэш зачёта (`AdminShell.ngOnDestroy`).

## Участники этапа (`participants.ts`)
Группы по 10 (по порядку регистрации или «перемешать»), перетаскивание между группами и внутри очереди (CDK drag&drop), «+ Группа», снять с этапа.
У каждого пилота под ником — ник Discord или «нет Discord». Кнопки тестовых пилотов — только локально (`isDevMode`).

## Пульт судьи `/judge/:id` — квалификация (`judge.ts`)
- Очередь по группам → `queue_order`; попытка 0 — прогрев, 1–2 — зачётные. Три поля (траектория, угол, стиль), шаг 0.5, максимум — вес критерия.
- После сохранения — автоматически следующая попытка/пилот; любую оценку можно поправить (подставляются сохранённые).
- Нулевая попытка с причиной: **спин / авария / выпрямление / вылет** (`fail`), на стриме — анимированная плашка.
- **Дисконнект (перезаезд):** пилот уходит в конец **своей группы**, оставшиеся попытки — после всех. **Дисконнект по своей вине** — без результата.
- Предупреждения пилотам (регламент 1.6). Несколько пультов одновременно — Realtime перезагружает данные, не стирая ввод.
- После последней оценки — статус «Квала завершена» (`qual_done`), сайт не горит LIVE до парных.

## Пульт судьи — сетка и дуэли (`battles.ts`, `bracket-ops.ts`)
- «Построить сетку» из итогов квалы: Top 32/16/8 (auto по числу пилотов), классический посев, баи сразу продвигаются.
- Дуэль: голосование трёх судей кнопками по пилотам (OMT посередине), роли подписаны «в 1-м заезде»; ≥2 голоса — победа, иначе OMT (максимум 2), дальше — лучший по квале.
- Техпоражение, **контакт** (врезался в соперника → поражение, ачивка «Божественное касание»), отмена решения (пока следующие пары не начались).
- Победитель продвигается, проигравшие полуфиналов — в дуэль за 3-е. Пары с протестом на рассмотрении помечены и не запускаются.
- После завершения этапа — состояние «завершено» с кнопкой пересчёта.

## Итоги этапа (`finish.ts`, `stage-results.ts`)
Места (дуэли + квала), очки по таблицам сезона, команда из **подтверждённого состава сезона** на момент завершения,
ачивки (`stageAchievements`), статус «Завершён», Discord-итоги. Повторный запуск пересчитывает.
Личный и командный зачёт этапа + ачивки показываются в админке.

## Discord-оповещения (откуда шлются)
Открытие регистрации, старт квалы, старт парных, итоги — из админки этапа (`notify`). Протест — от пилота. Подробно — [edge-functions.md](edge-functions.md).
