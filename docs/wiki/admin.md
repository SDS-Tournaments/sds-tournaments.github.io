## Участники этапа (`participants.ts`)
Группы по 10 (по порядку регистрации или «перемешать» — буферы не трогает), перетаскивание между группами и внутри очереди (CDK drag&drop), группы ▲▼, «+ Группа», **«+ Буфер»** (запасная группа со своим названием, напр. «EN сервер»; едет там, где стоит; обычные нумеруются без буферов — `groups.ts → groupLabel`; ✕ — пустой удаляется, с пилотами становится обычной группой), снять с этапа. Сохранение: сначала `stages.group_meta`, потом очередь — **только изменённые записи** (перезапись всех ~140 строк разом положила базу 2026-10-31).
У каждого пилота под ником — ник Discord или «нет Discord». Кнопки тестовых пилотов — только локально (`isDevMode`).

## Общий пульт судей (`judge-live.ts`, 0024)
- Плашка «Я оцениваю»: место = критерий или «Без оценки» + галочка «Главный судья» (в localStorage браузера). Подключённые — через Realtime presence; предупреждения: два судьи на одном критерии, нет главного.
- Выбор пилота/попытки общий (`judge_live.target`, null = следующий по очереди); после сохранения — снова null.
- Черновики `judge_marks`: судья правит свой критерий (главный — любой), уходит через 300 мс, у остальных подставляется сразу (кроме поля с курсором). ✓ — балл/голос поставлен.
- Сохранить / нулевая / прогрев / дисконнект / техпоражение, в парных — зафиксировать / техпоражение / контакт / отмена — **только главный**. После — черновики цели удаляются. На стрим попадает только сохранённое.

## Пульт судьи `/judge/:id` — квалификация (`judge.ts`)
- Очередь по группам → `queue_order`; попытка 0 — прогрев (если включён на этапе), 1–2 — зачётные; пилот «проехал» = есть попытки 1 и 2. Три поля (траектория, угол, стиль), шаг 0.5, максимум — вес критерия.
- После сохранения — автоматически следующая попытка/пилот; любую оценку можно поправить (подставляются сохранённые).
- Нулевая попытка с причиной: **спин / авария / выпрямление / вылет** (`fail`), на стриме — анимированная плашка.
- **Дисконнект (перезаезд):** пилот уходит в конец **своей группы**, оставшиеся попытки — после всех. **Дисконнект по своей вине** — без результата.
- **«→ В буфер»** (главный): пилот в конец первого буфера (нет — создаётся в конце очереди), очередь перенумеровывается. Новая группа на трассе → бот «едет / готовится» (`groups`); вручную — «📣 Группы в Discord».
- Предупреждения пилотам (регламент 1.6). Несколько пультов одновременно — Realtime перезагружает данные, не стирая ввод.
- После последней оценки — статус «Квала завершена» (`qual_done`), сайт не горит LIVE до парных.

## Пульт судьи — сетка и дуэли (`battles.ts`, `bracket-ops.ts`)
- «Построить сетку» из итогов квалы: Top 32/16/8 (auto по числу пилотов), классический посев, баи сразу продвигаются.
- Дуэль: голосование трёх судей кнопками по пилотам (OMT посередине), роли подписаны «в 1-м заезде»; ≥2 голоса — победа, иначе OMT (максимум 2), дальше — лучший по квале.
- Техпоражение, **контакт** (врезался в соперника → поражение, ачивка «Божественное касание»), отмена решения (пока следующие пары не начались).
- Победитель продвигается, проигравшие полуфиналов — в дуэль за 3-е. Пары с протестом на рассмотрении помечены и не запускаются.
- После завершения этапа — состояние «завершено» с кнопкой пересчёта.

## Пульт комментатора `/commentator/:id` (`commentator/`, staffGuard)
Только чтение, следует за пультом судей (`judge_live`), можно выбрать другого пилота и вернуться «↺ Вернуться к трассе». Realtime: оценки, дуэли, записи, `judge_live` (пачка изменений — одна перезагрузка); голоса зрителей по дуэлям — опросом раз в 3 с.
- **Квала:** очередь; досье пилота (`dossier.ts`: обложка-ливрея, **«О себе»** RU/EN от самого пилота, статистика, навыки, прошлые этапы, ачивки); живая колонка — попытки, «Чтобы…» (догнать лидера / пройти в сетку), **шансы на ачивки** (`chances.ts`: `qualChances`); справа «Далее» и таблица квалы.
- **Парные:** шапка дуэли с личными встречами и голосами зрителей, две карточки пилотов (путь по сетке, шансы `duelChances`, компактное досье), список дуэлей этапа.

## Итоги этапа (`finish.ts`, `stage-results.ts`)
Места (дуэли + квала), очки по таблицам сезона, команда из **подтверждённого состава сезона** на момент завершения,
ачивки (`stageAchievements`), статус «Завершён», Discord-итоги. Повторный запуск пересчитывает.
Личный и командный зачёт этапа + ачивки показываются в админке.

## Discord-оповещения (откуда шлются)
Открытие регистрации, старт квалы, старт парных, итоги — из админки этапа (`notify`). Протест — от пилота. Подробно — [edge-functions.md](edge-functions.md).
