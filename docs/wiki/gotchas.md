# Грабли и решения

Читать перед похожей правкой. Формат: симптом → причина → решение.

## Вёрстка и CSS
- **Карточка-ссылка при наведении красится в бирюзу и под ней линия** → глобальный стиль `a` (color + background-подчёркивание) →
  `.x, .x:hover { color: var(--ink); background: none; }`.
- **Старое правило осталось ниже нового и ломает размеры** (корешок билета был уже основы на 32px из-за `margin: 0 16px`) →
  при переделке компонента грепать все селекторы с тем же именем и удалять старые.
- **Свечение/тень обрезаются** → `mask` и `clip-path` режут `box-shadow`; свечение по форме — `filter: drop-shadow` на обёртке.
- **Светящаяся точка в вырезе билета** → (1) пунктир доходил до выемки — укоротить на `--r + 4px`; (2) прозрачный (`opacity:0`) рулон в зоне
  `drop-shadow` оставлял след после ховера — добавить `visibility: hidden` с задержкой.
- **Цвет рамки статуса перекрасил прозрачный верх** → `border-color` шорткат задаёт все 4 стороны; верх переопределить более специфичным селектором.
- **SVG обрезает элементы у края viewBox** (низ лаврового венка срезан по прямой) → `overflow: visible` на svg.
- **Стили темы перебивают размер** (`.legend .big { font-size: 52px }` сильнее `.big.w3`) → поднимать специфичность (`.fut .big.w3`).
- **Регулярка в шаблонной строке JS-скрипта теряет `\`** (`/^\/(me|admin)/` стала `/^/(me…`) → такие правки делать Edit'ом и проверять.
- **Плашка в 2 строки с `border-radius: pill`** выглядит овалом → фиксированный радиус (19px) + `text-align: center`.

- **Глобальный класс `.reveal`** (директива появления: opacity 0 + сдвиг) — не называть так свои классы (полоска прогноза пропадала). Свои состояния — `.closed`, `.done` и т.п.
- **Бюджет стилей компонента** поднят до 48 КБ (ошибка), предупреждение — 24 КБ: overlay.scss ~31 КБ.

- **Элемент с `aspect-ratio` в grid с `align-items: stretch`** растягивается по высоте соседа и вылезает по ширине (плеер Twitch заезжал под панель эфира) → `align-self: start; width: 100%; min-width: 0`.

## Angular
- **`routerLink` навигирует до анимации** → `[attr.href]` + `(click)` с `preventDefault` и `router.navigate` по таймеру.
- **`@property` в стилях компонента** работает — можно анимировать `--переменные` через `transition`/`@keyframes`.
- **Эмулированная инкапсуляция и `::ng-deep`** — для стилей дочерних компонентов (sonar за next-stage на /attack-shark).
- **Неиспользуемый импорт `RouterLink`** даёт предупреждение — убирать из `imports`.

## Данные и база
- **Select с несуществующей колонкой падает целиком** → код с новой колонкой не заливать до миграции (настройки открывались пустыми).
- **RLS не даёт ошибку при запрете update** — проверять, что строка записалась (`.select('id')`).
- **Повторная запись на этап — это update, а не insert** → триггер `prepare_registration` повешен и на update (0019).
- **`current_user` внутри `security definer` — владелец функции** → определять сервер через `auth.role()` (0019), не через current_user.
- **Кэш зачёта после правок в админке** → `clearStandingsCache` в `AdminShell.ngOnDestroy`.
- **Подиум на стриме до подведения итогов** — сегодняшней победы в базе нет → флаг `counted` в карточках.

## Сеть, деплой, браузеры
- **ERR_CONNECTION_RESET к `*.supabase.co`** (2026-10-20, один пользователь) — причина: **Яндекс Браузер** (блокировщик режет фоновые
  запросы к чужому домену; прямой переход по ссылке работает). В Edge всё работает. Если пожалуется много людей на Яндекс Браузере —
  делать прокси через Yandex Cloud API Gateway (не Cloudflare: в РФ его режут; Supabase сам за Cloudflare).
- **`/auth/callback` отдавал 404** → в CI копии `index.html` в `auth/callback.html` и `auth/steam.html`.
- **Обрывы связи** → `retryFetch` повторяет GET/HEAD до 2 раз (запись и вход — нет).
- **Переводы застревали в кэше после публикации** → переводы собираются с кодом (хеш в имени).
- **Пользователь видит старую версию** → Ctrl+F5.
- **Glitch-символы с кириллицей выглядели непереведёнными на EN** → мусор только из латиницы/символов.

## Инструменты
- **heredoc в bash ломается** на кавычках/обратных кавычках/`${}` → скрипты писать через Write в scratchpad.
- **`JSON.stringify` всего файла переводов** разворачивает компактные объекты → вставлять текстом.
- **Скрытая панель браузера**: rAF/анимации стоят, скриншот запаздывает, `documentElement.zoom` не влияет на скриншот (`body.zoom` — влияет),
  фиксированная шапка перекрывает увеличенный кадр. Проверять цифрами.
- **Долгие команды браузерного инструмента** уходят в фон — дождаться уведомления, не дублировать.
- **`gh` не установлен** — выкладку проверять curl-опросом сайта.
- **Модель 3D** со spec-gloss материалами не грузится в three r186 → `gltf-transform metalrough`, затем
  `optimize --compress meshopt --texture-compress webp --texture-size 1024 --simplify false` (17 МБ → 0.9 МБ). Исходники — `assets-src/` (в .gitignore).
