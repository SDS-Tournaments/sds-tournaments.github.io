# Подсчёт, сетка, очки, ачивки

Код: `src/app/scoring/scoring.ts` (чистые функции) + `scoring.spec.ts`. Правила — регламент SDS v2.0 и spec §5.

## Этап (два дня)
- **День 1 — квалификация** (`starts_at`): группы по 10, очередь; 3 заезда: прогрев + 2 зачётных.
  Три судьи — у каждого критерий: **траектория, угол, стиль** (этот порядок везде: пульт, настройки, плашки, карточка, паутинка).
  Балл 0…вес критерия (веса этапа, сумма 100; по умолчанию угол 40, стиль 30, траектория 30), шаг 0.5. Итог попытки ≤ 100.
- Нулевая попытка (`spin = true`, `fail` = spin/crash/straight/offtrack) → total 0.
- Результат пилота — лучшая из двух; ничья — выше худшая попытка, затем порядок выезда.
- Между днями — статус `qual_done`. **День 2 — Top 32** (`battles_at`, можно на другие выходные).

## Сетка (`bracketSize`, `seedOrder`, `buildBracket`)
auto: 32 при ≥17 пилотах, 16 при 9–16, 8 при ≤8. Классический посев (1 и 2 — только в финале). Не хватает пилотов — верхние посевы проходят по баю.
Лидер пары — лучший по квалификации.

## Дуэль (`battleOutcome`)
2 заезда (лидер меняется) → 3 голоса (leader/chaser/omt). ≥2 за пилота — победа; иначе OMT (до 2); после второго OMT без решения — лучший по квале (`qual_tiebreak`).
Техпоражение (`tech_loss`), контакт (`contact`), бай (`bye`). Победитель — в следующий слот; проигравшие полуфиналов — дуэль за 3-е.

## Места и очки (`stagePlaces`, `stagePoints`, RDS GP 2024)
Места: 1 финал, 2 финалист, 3/4 дуэль за 3-е, 5–8, 9–16, 17–32 (внутри группы — по месту в квале), дальше — по квале. DQ — 0 очков.
- Квалификация: 22, 19, 17, 15, 14, 13, 12, 11, 10, 9, 8, 7, 6, 5, 4, 3 (1–16), 17–32 → 2, 33+ → 1.
- Дуэли: 1 → 250, 2 → 180, 3 → 145, 4 → 120, 5–8 → 70, 9–16 → 30.
- Команда за этап — сумма 3 лучших (`team_counted`). Сезон — сумма этапов; ничьи: больше 1-х мест, 2-х…, побед в квале, место на последнем этапе.

## Навыки и рейтинг
`skills()` — средний % от максимума по угол/стиль/траектория по зачётным попыткам; `overall` 0–100; `mergeSkills` добавляет `profiles.legacy` (статистика до сайта).
Уровень карточки (`tier.ts`): <75 Bronze, 75–82 Silver, 83–89 Gold, 90–94 Elite, 95+ Legend.

## Хайп этапа (`components/hype.ts`)
Пороги записавшихся: 5, 10, 15, 20, 30, 40, 50, 65, 80, 100 → уровни 1…10. Визуал — [design.md](design.md#хайп-этапа).
