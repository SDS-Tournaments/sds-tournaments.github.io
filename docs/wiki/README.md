# Вики проекта SDS — база знаний для Claude

Это рабочая память о проекте: что где лежит, как устроено, как мы работаем и почему так решили.
Пишется для себя (Claude), язык — русский, как и весь проект.

**Обновлено:** 2026-10-25 (залив: трасса этапа и зоны).

## Правило
1. **В начале работы** — прочитать этот файл и страницы по теме задачи. Вики быстрее, чем перечитывать код.
2. **Перед каждым заливом в прод** (`git push` по команде «заливай») — обновить затронутые страницы вики
   и добавить запись в [changelog.md](changelog.md). Вики коммитится вместе с изменениями, отдельным коммитом
   `wiki: …` или в том же — главное, до пуша.
3. Если в вики что-то расходится с кодом — прав код; исправить вики.
4. `docs/spec.md` и `docs/plan.md` — исходная спецификация и план v1 (исторические, местами устарели:
   Netlify → GitHub Pages, однодневные этапы → двухдневные). Актуальное — здесь.
