# Плашки для стрима (OBS) и пульт трансляции

## `/overlay` (`overlay/overlay.ts`, `overlay.scss`)
Публичная страница без шапки/подвала, прозрачный фон, 1920×1080. Всегда в теме NOIR (тема сайта не влияет).
Слушает `overlay_state` и данные этапа через Realtime.

Параметры адреса:
- `?only=<widget>` — один виджет (для раскладки по разным источникам OBS);
- `?preview=1` — тёмная подложка вместо прозрачности (превью в пульте);
- `?skin=arena` — посмотреть стиль; `?stage=ID&show=duel,score` — без пульта, только чтение;
- `&poll=75` / `poll=none` / `pollDone=leader|chaser` (только с mock) — расклад голосов прогноза и показ итога (для UI kit);
- `?preview=1&mock=1` — вымышленный этап (`mock.ts`: 16 пилотов, квала, Top 16, дуэль с голосами, подиум); `?pair=ID` — конкретная пара.

### Виджеты (`state.ts` → `WIDGETS`)
| id | Что |
|---|---|
| `stage` | Стадия этапа (угол): этап, статус (в т.ч. «Квалификация завершена») |
| `onTrack` | На трассе: первый в очереди, у кого не все 3 заезда; группа, попытка |
| `score` | Оценка заезда: полоски траектория/угол/стиль заполняются по очереди сверху вниз, «Итог» набегает за 2 с (ease-out quint, шаг 0.5); нулевая попытка — анимированная плашка причины (спин/авария/выпрямление/вылет); живые ачивки под оценкой (серая → золотая для новой, ×N для повторной), прячутся после показа; авто-показ на 10 с после каждой новой оценки (`autoScore`) |
| `qualTable` | Таблица квалификации: ▲/▼ мест после оценки (8 с), лента «Новый лидер»; пустое состояние — скелетон-строки |
| `duel` | Дуэль: пара, голоса судей по одному, OMT, «Победа: ник» 10 с |
| `matchup` | Карточки дуэли: FIFA-карточки пары + сравнение (рейтинг, угол, стиль, траектория, победы) |
| `bracket` | Сетка на весь экран (масштаб под Top 32/16/8) |
| `podium` | Подиум на весь экран: 2—1—3, поэтапное появление, серебро/бронза, лучи, корона, конфетти; FIFA-карточки; через 2.8 с победитель «повышается» до карточки чемпиона с прилётом новой звезды (работает и до подведения итогов) |
| `sponsors` | Ротация спонсоров (`on_overlay`) |
| `protest` | «Протест на рассмотрении» |
| `poll` | Прогноз зрителей: живое распределение голосов. Квала — панель справа внизу (6 полосок). Парные — **полоска над плашкой дуэли**, выезжает из-за неё (z-index ниже, высота дуэли замеряется ResizeObserver → `stripBottom`; снизу запас под капсулу раунда): ширина = ширине дуэли (тоже замер); слева % за лидера, справа за чейзера, между ними **два луча навстречу** — цвет и свечение по проценту (--heat, как у оценок: бирюза → фиолет → красный), на стыке частая мерцающая вспышка (0.32 с) «столкновения лазеров» + 14 искр веером (`sparks` в overlay.ts, разлёт через cos/sin угла, лёгкое «падение»). Подпись «Прогноз зрителей · Голосуй на сайте» (число голосов не показываем). Без голосов — лучи тусклые, вспышки и искр нет. **Итог дуэли** (класс `.closed.win-l/.win-r`, 3.4 с): «Угадали: N%» на текущем раскладе → вспышка разрастается и катится к проигравшему (перекат ведёт код: `showReveal` → сигнал `revealX` по rAF, 30–78% времени, ease-in-out; проценты и цвет лучей считаются от него же, у победителя в конце 100%), луч победителя забирает полоску → финальная вспышка → через 4.2 с полоска уезжает. Пока на плашке дуэли «Победа: ник» (FLASH_MS = 10 с), прогноз следующей пары не показывается — появляется вместе со следующей дуэлью. Свой вид в каждом из 4 стилей (в «Гонке» — тот же наклон, что у дуэли); после оценки/решения 8 с показывает правильный вариант и «Угадали: N%». В тестовых данных — 62/41 на текущую дуэль |

### Состояние `overlay_state.state`
`{ lang: 'ru'|'en'|'auto', stageId, visible: {widget: bool}, autoScore, mock?, skin? }`.
- `lang: auto` — смена RU ⇄ EN каждые **8 с** (`LANG_SWAP_MS`), полноэкранные (сетка, подиум, карточки пары) — каждые **4 с**; текст плавно гаснет и проявляется.
- Скины: classic, arena, race, **hud** (по умолчанию).
- Тексты плашек — `OVERLAY_TEXT` в `state.ts` (свой RU/EN, независимо от языка сайта).

## Пульт трансляции `/broadcast` (`overlay/broadcast.ts`)
Только штаб, RU, всегда NOIR. Выбор этапа (по умолчанию идущий), переключатели плашек, язык (RU/EN/авто), авто-оценка, скин,
«Тестовые данные» (mock), превью 16:9 и ссылка для OBS (источник «Браузер», 1920×1080).
